# VR Аренда - Сайт визитка с неоновым дизайном

Современный сайт-визитка для бизнеса по аренде VR-гарнитур с анимированным фоном, плавными переходами и неоновым оформлением.

## ✨ Особенности

- **Анимированный фон** с частицами (particles.js) и градиентными переходами
- **Неоновый дизайн**: электрические цвета, светящиеся эффекты, анимированные границы
- **Плавные анимации** при скролле и наведении
- **Адаптивная верстка** - выглядит отлично на всех устройствах
- **Две страницы**:
  - Главная страница (визитка) с информацией об услугах, portfolio и контактами
  - Страница магазина с каталогом VR-гарнитур для аренды
- **Секции**:
  - О нас
  - Наши услуги (игровые сессии, обучение, бизнес)
  - Portfolio с наложениями
  - Контактная форма
  - Информация о работе сервиса (на странице магазина)

## 🛠️ Технологии

- HTML5
- CSS3 (с кастомными свойствами, анимациями,flexbox/grid)
- JavaScript (частицы через particles.js, анимации при скролле)
- Font Awesome 6 для иконок
- Google Fonts (Segoe UI fallback)

## 🎨 Цветовая схема (неоновая)

- **Фон**: темный (`#000000`) с радиальными градиентами
- **Неоновые цвета**:
  - Синий: `#00ffff`
  - Розовый: `#ff00ff`
  - Зеленый: `#00ff00`
  - Пурпурный: `#bf00ff`
  - Оранжевый: `#ff6600`
- **Текст**: белый (`#ffffff`) с неоновыми тенями
- **Элементы интерфейса**: полупрозрачные темные фоновые слои с неоновыми границами

## 📱 Адаптивность

Сайт полностью адаптивный:
- На мобильных устройствах меню и секции стекаются в одну колонку
- Изображения и карточки товаров сохраняют пропорции
- Размеры шрифтов и отступов автоматически подстраиваются

## 🔧 Настройка

Чтобы изменить содержимое:
- Текст и структуру - редактируйте HTML файлы
- Стили - файл `css/style.css`
- Изображения - замените SVG файлы в папке `images/` (можно использовать свои изображения в формате JPG/PNG, обновив пути в HTML)
- Конфигурацию частиц - в `js/main.js` (объект конфигурации particlesJS)
